# NFL Stats Explorer (first-N-seasons)

Interactive scatter plots of NFL passing and total production over a player's first *N* seasons
(1–23), with a play button, playoff filters (incl. / excl. / playoffs only / playoffs without the
wild-card round), and player highlighting.

**Updates itself:** a GitHub Action runs every morning, pulls the latest
[nflverse](https://github.com/nflverse/nflverse-data) stats, and redeploys the site if any
regular-season or playoff games were added. Preseason is ignored.

## Files

| File | What it does |
|---|---|
| `index.html` | The whole site (D3.js chart, controls, tables) |
| `players.json` | Per-season data the page reads first, generated by `build_data.py` |
| `games.json` | Per-game data, loaded when the slider is switched to Games |
| `build_data.py` | Downloads nflverse stats (1999 → current season) and builds `players.json` |
| `.github/workflows/update-data.yml` | Daily schedule: rebuild data → commit if changed → deploy to Pages |

## Run locally

```bash
pip install -r requirements.txt
python build_data.py          # refresh players.json
python -m http.server 8000    # then open http://localhost:8000
```

## Notes

- Seasons count from the rookie year; "games" = games with at least one recorded stat.
- The current season is detected automatically (September onward = new season).
- 1970–1998 regular seasons come from [fantasydatapros/data](https://github.com/fantasydatapros/data)
  (snapshot in `data/`). Checked against nflverse for every overlapping player-season 1999–2021
  (~99% exact) and against NFL.com for Marino, Emmitt Smith and Jerry Rice (exact).
  These players show only with Playoffs: Excluded and the slider on Seasons, except Marino, Favre and
  Kelly (playoffs entered by hand) and Manning and Warner (no pre-1999 playoff games).
- Three regular-season games missing from nflverse (1999 Rams–Ravens, 2000 Chiefs–Chargers and
  Bills–Dolphins) are filled in from the season totals.
